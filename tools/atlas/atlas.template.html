Adewale Oshineye Atlas

Atlas

A map of the work rather than a list of it. Every repository is a star; its cluster is the theme it belongs to, the maroon lines trace lineage — what grew from what — its colour is the language, and its size is how many other projects descend from it. Filled stars are the projects I'm currently featuring; the Cloudflare toggle spotlights everything built on the platform. The layout is computed once and frozen, so nothing jitters.

  • size = projects descended from it
  • line = lineage (parent → child)
  • cluster = shared theme
  • filled = currently featured
