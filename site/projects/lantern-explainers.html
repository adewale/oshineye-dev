Adewale Oshineye Lantern Explainers

Lantern Explainers

Each explainer is one TypeScript Scene. A web page steps through it at the reader’s pace, and the same scene can render a silent, captioned video.

It is a fork of Lantern by Ivar Vong. Diagrams come from Agentic Mermaid at build time and are stored beside the scene, so the page runs no diagram renderer and makes no network requests.
