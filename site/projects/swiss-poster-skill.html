Swiss Poster Skill

Agent Skill

A Swiss poster design system for AI agents — huge type, grid-breaking layouts, overlap, bleed, and hard figure/ground drama, all in Tailwind CSS.

Tension over comfort.

Point an agent at a flat page and ask for the Swiss Poster style. It returns extreme scale contrast, layered elements, a single bold accent, and type cropped by the viewport edge — the grammar of mid-century Swiss poster design, applied to the web.

What the skill applies

  • Treat the 12-column grid as a launchpad, then let key elements escape it.
  • Push extreme scale contrast — 10×+ size ratios between display and body type.
  • Overlap and layer elements with deliberate z-index stacking.
  • Bleed and crop: type cut by the viewport edge, elements running off-screen.
  • Commit to one accent color, used boldly — Swiss red by default.
  • Choose tension over comfort with asymmetric spacing, rotation, and diagonal energy.

Install and use

With the Skills CLI

npx skills add adewale/swiss-poster-skill

Or copy the skill folder

cp -r swiss-poster ~/.config/opencode/skills/

Example prompt

Make this look dramatic — use the Swiss Poster style.

Output targets Tailwind CSS with IBM Plex Sans, a stone palette, and a single Swiss-red accent — with Barlow Condensed, IBM Plex Serif, and IBM Plex Mono available per context.
