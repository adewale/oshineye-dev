The second commit: Add world.txt

  1. A blob id is the SHA-1 of typed bytes

    Git hashes a header (the type, the byte length and a zero byte) followed by the content. The id is the SHA-1 of exactly these 13 bytes, and later pictures name it by its first seven digits.

    • The content bytes "hello\n", one cell each with its hex value;
    • The header bytes “blob 6” and a zero byte, in front of the content;
    • An arrow labelled SHA-1 from the bytes to their id;
    • The blob id ce013625030ba8dba906f756967f9e9ca394464a, its first seven digits highlighted.
  2. A tree gives those bytes a name

    A tree entry stores a mode, the name hello.txt and the blob’s id. Hashing the tree’s own bytes gives it an id too. The name lives in the tree, never in the blob.
