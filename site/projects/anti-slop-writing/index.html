Anti-Slop Writing

Agent Skill

Anti-Slop Writing helps coding agents review, draft, and rewrite prose so it does not read like generic LLM output.

Sharp detail beats inflated significance.

Use it for READMEs, articles, slide copy, wiki pages, emails, launch posts, scripts, product copy, and DevRel writing where generic cadence, prestige abstractions, or marketing fog would weaken the work.

View anti-slop-writing on GitHub

Installable unit

The skill is instruction-only: it does not run scripts, install packages, call the network, or require a runtime.

01

What it asks the agent to do

  • Replace vague importance language with specific mechanisms.
  • Detect canned AI-writing rhythms such as decorative contrast and “not just X but Y”.
  • Improve paragraph flow by naming cause, contrast, dependency, inference, or level change.
  • Turn generic conclusions into endings that return to the concrete carrier.
  • Preserve useful compression while removing cadence that pretends to be judgment.

02

Before and after

These compact cards come from the repository’s before/after examples.

Replace importance with mechanism

Before

This underscores the importance of durable execution.

After

The workflow can fail on step 4, retry only that step, and keep the previous outputs.

The rewrite names the behavior that makes execution durable. It no longer asks the reader to accept importance as a substitute for evidence.

Cut safe essay voice

Before

In today's rapidly evolving landscape, teams need robust solutions that empower developers to build seamless experiences.

After

A frontend developer can ship a shared cart without running a sync service.

The rewrite names an actor, an action, and a concrete result. It drops the stock frame and unsupported adjectives.

Add a level-of-detail hinge

Before

The Climb ranks the models.

Head-to-Head is a filmstrip viewer.

Runbook Diffs compares versions.

After

The site exposes the run at three resolutions. The Climb shows the aggregate trajectory, Head-to-Head shows round-by-round lineage, and Runbook Diffs drops to the source level where the prompt and seed SVG changed.

The rewrite turns three adjacent feature descriptions into one inspection model.

Replace rhythm with relation

Before

The point is not the pelicans. The point is the process.

After

The pelican is useful because it gives the process a small, inspectable carrier.

The rewrite keeps the concrete example and explains how it supports the larger claim.

Return to the carrier

Before

A benchmark is stronger when you can inspect the run that produced it.

After

Because the pelican project is small enough to inspect and strange enough to remember, it works as a compact carrier for the larger claim: a benchmark is stronger when you can inspect the run that produced it.

The conclusion returns to the memorable object before stating the transferable claim.

03

Install and use

With the Skills CLI

npx skills add https://github.com/adewale/anti-slop-writing --skill anti-slop-writing

Or copy the skill folder

mkdir -p ~/.agents/skills
cp -R skills/anti-slop-writing ~/.agents/skills/

Example prompt

Use the anti-slop-writing skill to review this README intro. Flag slop tells and give a concrete rewrite.

The README lists Pi, Claude Code, Codex, OpenCode, claude.ai, and the Claude API as compatible clients.
