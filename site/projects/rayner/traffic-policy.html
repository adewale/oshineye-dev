How does traffic policy divide requests among pods?

A Service of type LoadBalancer: a cloud load balancer sends outside requests to the nodes, and rules that kube-proxy writes on each node hand every request to a pod. Node 1 runs 3 pods, Node 2 runs 1 and Node 3 runs none. The Service’s externalTrafficPolicy sets which pods a node may pick: under Cluster, the default, any pod in the cluster; under Local, only the pods on that node. This one is set to Local.
