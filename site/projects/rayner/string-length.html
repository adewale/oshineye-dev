Why does one word have three lengths?

A sign-up form limits a name to ten characters, and someone types नमस्ते, namaste. How long is that? It depends on what is counted: 18 bytes, 6 code points, or the 3 characters a reader sees. None of the three is wrong. Bytes, code points and the characters a reader sees are three different counts of the same text. The next steps take the word apart to find each number.

Transcript
  1. One word, three lengths: 18, 6 and 3

    A form allows ten characters. Is this word too long?

    A sign-up form limits a name to ten characters, and someone types नमस्ते, namaste. How long is that? It depends on what is counted: 18 bytes, 6 code points, or the 3 characters a reader sees. None of the three is wrong. Bytes, code points and the characters a reader sees are three different counts of the same text. The next steps take the word apart to find each number.

    • नमस्ते. namaste: a greeting. Bytes, in UTF-8. 18. Code points. 6. Characters a reader sees. 3.
  2. Six code points: the numbered parts the word is stored as

    Each cell is one code point; U+0928 is its number in Unicode.

    To a program, text is a list of code points, numbers that Unicode assigns to letters and marks: U+0928 is the letter na. This word needs six. Four are letters. One, U+094D, is a joiner: it tells the letter before it to fuse with the next. The last is a vowel mark that sits on a letter. The dotted ring stands for the letter a mark would sit on. Python’s len() counts these: 6.

    • Six cells, one for each code point of नमस्ते;
    • Under each cell its code point and what it is: U+0928 letter, U+092E letter, U+0938 letter, U+094D joiner, U+0924 letter, U+0947 mark.
  3. 18 bytes: UTF-8 writes each of these code points as three

    Bytes are what a file, a column or a packet holds.

    To store or send the word, each code point is written as bytes. UTF-8 uses one byte for the first 128 code points, which cover English, two for the next couple of thousand, and three for the tens of thousands after those, including every Devanagari letter. So the first code point, U+0928, becomes E0 A4 A8, and the six code points become 18 bytes. A limit set in bytes is the tightest of the three.

    • Six cells, one for each code point of नमस्ते;
    • Under each cell its code point and what it is: U+0928 letter, U+092E letter, U+0938 letter, U+094D joiner, U+0924 letter, U+0947 mark;
    • Under each code point its three UTF-8 bytes, first byte on top; the first, U+0928, is E0 A4 A8.
  4. Three characters: a mark or a joined letter belongs to the letter before

    What a reader sees, and a cursor steps over, as one: a grapheme cluster.

    A reader sees three things in this word. The joiner fuses two letters into one shape and the vowel mark rides on it, so the last four code points are drawn as one shape and selected as a single character, स्ते. Unicode calls such a unit a grapheme cluster and gives rules for finding one. Counted this way the word is 3 long, and it fits the form with room to spare.

    • The same six cells, drawn together where they make one character: 1, 1, 4 cells;
    • Each character as a reader sees it, over the code points that make it: न from 1, म from 1, स्ते from 4.

  6. Seven: three of them are points on a letter

    4 characters, 7 code points, 14 bytes.

    Each point is a code point of its own. The first letter carries two, its vowel and the dot that makes it sh, and the third carries one, so four characters are 7 code points, and at two bytes each in UTF-8, 14 bytes. Written without its points, as everyday Hebrew usually is, the same word is 4 code points and 8 bytes. Its length to a reader has not changed: still 4 characters.

    The answer is “7”.

    • שָׁלוֹם, shalom, and its four characters in cells, read from the right;
    • Seven cells, one for each code point of שָׁלוֹם, from the right;
    • Under each cell its code point and what it is: U+05E9 letter, U+05B8 mark, U+05C1 mark, U+05DC letter, U+05D5 letter, U+05B9 mark, U+05DD letter.
  7. Five greetings, three counts each

    Only hello has one length.

    The same three counts for five greetings. hello is 5 by any of them, which is why code that confuses them passes its tests in English. Chinese has no marks, so code points and characters agree, but each character takes three bytes. Hebrew and Arabic carry their marks as extra code points. Hindi fuses letters. The further a script is from one letter, one code point, one byte, the further its counts drift apart.

    • In. Word. Bytes. Code points. Characters. English. hello. 5. 5. 5. Chinese. 你好. 6. 2. 2. Hebrew. שָׁלוֹם. 14. 7. 4. Arabic. سَلَام. 12. 6. 4. Hindi. नमस्ते. 18. 6. 3.
  8. Cut by bytes or code points and a character can be cut in half

    To shorten text for a reader, cut between characters.

    The form’s limit has to cut somewhere. Keep 10 bytes and the fourth code point is split, so it goes: three bare letters are left, and the last character has lost its joined letter and its vowel. Keep 4 code points and the word ends on a joiner with nothing to join, a stray stroke under the last letter. Keep 2 characters and both are whole. Store and send bytes; count and cut what people read in characters.

    • The first 10 bytes. the last character is cut short. नमस. The first 4 code points. ends on a joiner. नमस्. The first 2 characters. whole characters. नम.

Check yourself

  1. The Arabic greeting سَلَام is four letters with a vowel mark on each of the first two. What are its three lengths?

    Show the answer

    12 bytes, 6 code points and 4 characters. Each of the two vowel marks is a code point of its own that rides on the letter before it, and every code point of this word takes two bytes in UTF-8.

  2. A database column holds ten bytes of UTF-8. How many characters of नमस्ते fit in it whole?

    Show the answer

    Two: न and म, 6 bytes. The third character, स्ते, is four code points and needs 12 bytes, more than the 4 left. Cutting at byte 10 would also split a code point, since each takes three bytes.

  3. Why does the word hello never show any of this?

    Show the answer

    Its five letters are five code points below U+0080, which UTF-8 writes as one byte each, and none of them is a mark or a joiner. So all three counts are 5, and code that confuses them passes every test written in English.
