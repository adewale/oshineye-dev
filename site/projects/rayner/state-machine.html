Session history: Connect then close

  1. What can this event change?

    A transition needs both the current state and the event.

    CONNECT moves idle to connecting. In that state, OPENED moves the session to open. The event alone is not the rule: the reducer selects a transition using both the current state and the event.

    • idle. connecting. open. CONNECT. OPENED. Current state + event → next state.
  2. Can a late OPENED reopen it?

    closed has no OPENED transition.

    CLOSE moves open to closed. A later OPENED has no closed:OPENED transition, so the reducer throws InvalidTransition. The state remains closed.

    • CLOSE → closed. closed. OPENED. closed. ×. InvalidTransition. State stays closed.
