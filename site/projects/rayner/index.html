Adewale Oshineye Rayner

Rayner

Interactive explanations of protocols, algorithms and code changes. For engineers and technical educators who write TypeScript.

Step through a picture at your own pace, or change a setting to follow another case. The model computes the numbers, diagrams and captions. Publish a portable HTML page with a transcript and no runtime network requests.

Build them yourself

git clone https://github.com/adewale/rayner && cd rayner
npm ci
npx playwright-core install chromium
npm run demos:build
npm run demos:serve

Node 24 or later and Chromium. Authoring targets Ubuntu and macOS. Diagrams are captured at build time with Agentic Mermaid; the engine is forked from Ivar Vong’s Lantern.
