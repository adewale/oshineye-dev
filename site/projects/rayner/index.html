Start with a question. The author code sits beside two results; change one input to see what the model does. These are excerpts from three complete lessons with sources and limits.

Why does a cache hit skip D1?

Author code (selected lines)

const path = PATH[which];
await flow.walk(path, { trail: true });
this.state.reads =
  which === 'hit' ? 0 : 1;

Full scene

Result: one changed input

Row in KV: 0 D1 reads

No row in KV: 1 D1 read

A miss reads D1 and caches the row for 300 seconds. This is a model, not a latency benchmark.

Why do later requests get different answers?

Author model (excerpt)

this.tokens = Math.min(
  this.capacity,
  this.tokens +
    (now - this.lastRefill) * this.rate
);
this.lastRefill = now;
if (this.tokens < 1) return false;
this.tokens--;
return true;

Condensed from TokenBucket.allow; full scene.

Result: refill rate changes

1 token/s: R6, R7, R9 rejected

4 tokens/s: only R6 rejected

R6 arrives before any refill can help it. Later calls use the same arrival times at both rates.

Build them yourself

git clone https://github.com/adewale/rayner && cd rayner
npm ci
npx playwright-core install chromium
npm run demos:check
npm run demos:serve

Node 24 or later and Chromium. Authoring targets Ubuntu and macOS. Diagrams are captured at build time with Agentic Mermaid; the engine is forked from Ivar Vong’s Lantern.
