Why Rayner measures glyphs before drawing text

Why can the same word take different space in two fonts? Each letter is an outline from a font bundled with Rayner, with an advance that tells the next letter where to start. Write traces those contours here; the close-up shows points and handles. The next step compares the measured widths before later steps show what changes during a morph. No installed font is needed.

  2. Inter and JetBrains Mono give the same words different widths

    Ticks mark each pen position; the brace spans the measured width.

    The shaper gives every glyph an exact advance; the ticks mark each pen position and the brace spans the measured width. The boxed letters are Inter’s widest and narrowest; in JetBrains Mono every glyph has the same advance.

    • Boxes around Inter’s widest and narrowest letters, “H” and “l”, in both rows;
    • 3 labelled values:

      • JetBrains Mono advances: 0.540 each;
      • Inter − JetBrains Mono: -2.0848 units.
    • 3 labels:

      • 6.0152 units · Inter;
      • 8.1000 units · JetBrains Mono.
  3. The same letter is a different outline in each font

    Every glyph pairs with its 60% copy; across fonts, none pair.

    TransformMatchingShapes pairs glyphs whose outlines are the same path once each is centred and scaled to one size, so position and size do not count. Every glyph pairs with its own copy at 60% size; across the two fonts nothing pairs, not even the same letter.

    • Lines join each of the 14 glyphs of the top row to its smaller copy; nothing joins the JetBrains Mono row;

      • 0 of 14 paired.
  4. Rayner converts every font segment to a cubic

    218 font segments in, as many cubics out, for SVG and PNG.

    The font stores quadratic curves and lines, as the note beside it counts. Rayner raises every segment to a cubic, so one kind of path feeds both the SVG player and PNG stills.
