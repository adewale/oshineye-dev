How can a still skip the frames before it?

A direct link opens a later picture without playing the earlier steps, so Rayner makes that picture as a still. Here a box fades in, then a dot moves along a track. A nudge, as a game loop would make it, shifts the dot 1/30 of the track per computed frame. Playback has the dot halfway at t = 1 s. To make the still, Rayner re-runs the scene and counts frames 1–29 without computing them. Predict where the still’s dot will be before you go on.

The dot moves by: Blending fixed endpoints

  1. Played, the dot is halfway at t = 1.00 s

    A still at t = 1 s skips computing frames 1–29. Where is its dot?

    A direct link opens a later picture without playing the earlier steps, so Rayner makes that picture as a still. Here a box fades in, then a dot moves along a track. Rayner’s animate.moveTo moves the dot by blending its start and end. Playback has the dot halfway at t = 1 s.   2. The still matches: the same SVG, fingerprint ce5b0812

    Blending works the dot out from the time alone.

    The pictures match because animate.moveTo calculates position from elapsed time and fixed endpoints. It does not need the earlier dot positions. A still re-runs the scene on the same fixed clock and, unless the scene has updaters or is playing a Succession, skips computing the frames before t, so it matches playback whenever each frame depends on the time alone, and can miss when a frame depends on how many frames ran before it.

    • Two frames of the tiny scene at t = 1.00 s, played and seeked, both with the dot halfway and the fingerprint ce5b0812.

  4. Frame 30 is t = 1.00 s in every run

    Scene time is the frame number × 1/30 s, however fast the frames are taken.

    The receiver of a frame is called a sink. A browser sink waits between frames; a trace sink can take them immediately. That changes how fast the output arrives, not the scene’s clock: both reach t = 1 s at frame 30. The target time therefore identifies the same frame even when earlier pictures are skipped.

  5. A frame is the shapes on stage, as the playing animations left them

    Once the still reaches frame 30, the playing animation decides where the dot is.

    A Scene owns the shapes and text, called mobjects, and its animations change them. Rayner’s sinks only read the frame. The output cannot reconstruct missing nudges: the dot’s position must already be right when the animation hands over that frame.

    • Class diagram: 4 classes, 3 relationships:

      • Sink frame();
      • Mobject points style;

    • Beside Sink: it reads each frame and changes nothing.
  6. An animation fixes its endpoints when it begins

    At t = 1 s the blend is halfway, however many frames ran before.

    begin() copies the starting object. Each frame blends that copy with a fixed end by an amount set only by how far through its run time the animation is. Halfway through the duration therefore means halfway between the endpoints. In contrast, dot.shift(step) adds to the position accumulated by earlier frames.

Check yourself

  1. In the nudge version, the fade-in is stretched from 0.5 s to 1 s, so the move runs from t = 1 s to 2 s and the scene has 60 frames. Does the still at t = 1 s now match playback, and which is the first frame whose still differs?

    Show the answer

    The still at t = 1 s matches: frame 30 is now the last frame of the fade, and neither run has nudged the dot yet. The first frame that differs is 32. Frame 31 opens the move, and the seek and playback have each made one nudge there; by frame 32 playback has made two and the seek still one.

  2. Another version moves the dot by the change in time since the last frame it computed: x += distance × (α − α at the last frame). Does its still at t = 1 s match playback?

    Show the answer

    Yes. begin() computes α = 0, the skipped frames are never computed, and the frame at t = 1 s adds the whole change from 0 to 0.5 in one go, so the dot is halfway, as in playback. Keeping state is allowed, as long as the frame comes out the same however many frames ran before it.

  3. You write a typing animation: each computed frame appends the next character of a 60-character sentence, over a 2-second run at 30 fps. What does a still taken 1 s into that run show, and what change makes it match playback?

    Show the answer

    Playback has computed 30 frames by then and shows 30 characters; the still computes only the frame at t and shows about one. Show the first round(60 × α) characters instead, where α is the elapsed share of the run: each frame then depends on the time alone, and both show 30 characters at the midpoint.
